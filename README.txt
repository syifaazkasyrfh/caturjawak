CATUR JAWA - REVISI OFFLINE

Cara menjalankan di laptop:
1. Ekstrak ZIP.
2. Buka file index.html dengan Chrome.
3. Game langsung berjalan tanpa internet.

Cara memakai di CodePen:
1. Buat Pen baru.
2. Copy isi index.html ke HTML.
3. Copy isi style.css ke CSS.
4. Copy isi script.js ke JS.
5. Tidak perlu menambahkan library eksternal.

Catatan:
- Versi ini tidak memakai Chess.js atau CDN.
- Aturan dasar catur sudah dibuat langsung di JavaScript.
- Mendukung gerakan legal, capture, check, checkmate, castling,
  en passant, promosi pion, stalemate, dan aturan 50 langkah.
